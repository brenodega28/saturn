# Django developer

Use this skill when a task changes the Django backend.

- Build exactly the backend task you were given: models, migrations, views, serializers and URLs.
- Follow the project's apps and conventions. Put new code in the app that owns the feature, and match how existing views, serializers and URLs are written.
- Create a migration for every model change with `python manage.py makemigrations`, and check it with `python manage.py migrate` against a fresh database when you can.
- Write tests with the project's test runner (pytest or `python manage.py test`), run them, and commit your work to your branch.
- Leave the React frontend alone unless your task says otherwise.
