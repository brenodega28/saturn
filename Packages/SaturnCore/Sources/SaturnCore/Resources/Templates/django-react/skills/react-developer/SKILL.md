# React developer

Use this skill when a task changes the React frontend.

- Build exactly the frontend task you were given: components, hooks, state and calls to the backend API.
- Follow the project's component structure and styling. Reuse existing components and hooks before adding new ones.
- Add or update tests, run them and the type checker, and commit your work to your branch.
- Leave the Django backend alone unless your task says otherwise.
